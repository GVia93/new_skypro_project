# new_skypro_project


## Описание

Проект содержит следующие классы:
- `Product` — базовый класс товара.
- `Category` — класс для категорий товаров.
- `Smartphone` — подкласс `Product`, описывающий смартфоны.
- `LawnGrass` — подкласс `Product`, описывающий газонную траву.

Также реализовано:
- Инкапсуляция, геттеры и сеттеры.
- Подсчет созданных объектов.
- Перегрузка оператора `+` для расчета общей стоимости.
- Валидация данных при установке цены.
- Исключения при попытке некорректных операций.

## Структура проекта

- `main.py` — реализация логики классов.
- `test_main.py` — тесты с использованием `pytest`.
- `pyproject.toml` — настройки Poetry, зависимости и линтеры.

## Установка

Убедитесь, что у вас установлен Python >= 3.13 и Poetry.

```bash
poetry install
```

## Тестирование

```bash
pytest
```

С покрытием:

```bash
pytest --cov=main --cov-report=term-missing
```
